# Bun CLI test

```bash
bunx copilotkit@latest create
bunx copilotkit@latest whoami
bunx copilotkit@latest project select
cd myapp
bun install
bun run dev
```

Run `bun run dev` from `myapp`, not from this documentation folder. The `dev`
script is defined in `myapp/package.json`.

Use a separate generated project name such as `cli-test-bun`.
