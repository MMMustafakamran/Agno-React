# Findings — Agno-react

Doc defects / doc-vs-implementation discrepancies. Moved from `README.md` §9 on 2026-09-23; numbers unchanged. Docs base: `https://docs.copilotkit.ai/agno`.

**Versions.** #1–17: `@copilotkit/react-core` 1.66.2 (shipped `.d.ts` correct, prose stale). #18–31: react-core/runtime **installed 1.72.0, declared `^1.69.2`** (never `^1.72.0`; corrected 2026-09-23); `@copilotkit/core`, `web-inspector` 1.72.0 transitive; `@ag-ui/agno` 0.0.6; `@ag-ui/client` 0.0.59 (`0.0.x`); `@ag-ui/core` 0.0.59, `streamdown` 1.6.11, `rxjs` 7.8.1, `@langchain/core` 1.2.11 (transitive); `next` 16.3.3; `zod` 4.4.3. Note: #2 and #9 interact — `CopilotKitProvider` (needed for `code`) silently disables the inspector.
